# 哄睡啦音频资源

供 https://hongshuila.com/ 通过 GitHub Pages 加载的独立音频仓库。本站应用源码不在本仓库中。

音频位于 `audio/`，版本化文件名保持稳定，`manifest.json` 记录逐文件字节数和 SHA-256。更新声音时新增版本文件，不覆盖已经发布的版本。

作者、来源、适用许可和处理记录见 [audio/CREDITS.txt](audio/CREDITS.txt)。四份原始实录分别遵循对应 CC 许可；其余 26 份导入文件保留真实来源状态，来源未公开逐条开放许可。本仓库不将其标为 CC 或自制作品，也不统一授予所有音频同一种许可。

公开仓库与 Pages 资源可被下载或引用。GitHub Pages 有站点大小和流量限制，详见 GitHub 官方说明。本仓库不包含网站程序、账号数据、令牌或服务器配置。
